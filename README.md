# K-Vibe ✨ - AI Personal Stylist

🌐 **Live Demo:** https://chipper-medovik-83309c.netlify.app

An AI-powered web app that gives personalized outfit recommendations based on body type, skin tone, occasion & style.

### ✨ Features
- 👗 Personalized styling based on user inputs
- 🎨 Skin-tone based color matching
- 📅 Occasion-wise suggestions (College, Party, Casual, Wedding)
- 📱 100% Mobile Responsive

### 💻 Tech Stack
HTML5 | CSS3 | JavaScript | GitHub | Netlify

### 🚀 How It Works
1. User enters body type, skin tone, occasion
2. AI suggests best outfit combinations
3. Instant results!
